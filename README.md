# ЛР4 — Календарь

Учебное приложение на Flutter по ТЗ «ЛР04_Календарь.docx».
Календарь построен вручную на `GridView.builder`, без готовой библиотеки календаря.
Для сохранения используется знакомый по ЛР3 пакет `shared_preferences`.

## Возможности

- Просмотр месяца и переход между месяцами и годами.
- Выбор даты и список её событий, отсортированный по времени начала.
- Обводка сегодняшней даты; переключение месяца сохраняет выбранный день.
- Создание, редактирование и удаление события.
- Название, дата, время начала и необязательное время окончания.
- Проверки пустого названия, существования даты и допустимого времени.
- Тёмно-серая тема со светлым текстом.
- Приглушённые числа соседних месяцев вместо пустых ячеек; нажатие открывает их месяц.
- Автоматическое двоеточие в обоих полях времени: `12` → `12:`, `1230` → `12:30`.
- Выбор цвета события вместо категорий.
- Дополнительное задание из ТЗ: локальное сохранение событий.
- Небольшие дополнения: точки под датами с событиями и кнопка «Сегодня».

Цвета: «Красный», «Оранжевый», «Жёлтый», «Зелёный», «Голубой», «Синий», «Фиолетовый», «Серый».
Это небольшая палитра с привычными названиями; связи с Google Таблицами нет.

События сохраняются после создания, изменения и удаления. При запуске они загружаются обратно.
В браузере `shared_preferences` использует LocalStorage: список хранится строкой JSON под ключом `calendar_events`.
Это локальное хранение, без сервера и учётной записи.
Используй один браузер и тот же адрес с тем же портом: `http://127.0.0.1:8754`.
`localhost`, `127.0.0.1` и другой порт относятся к разным адресам хранения.
Очистка данных сайта или приватный режим могут удалить данные.
Окончание, если указано, должно быть позже начала в тот же день.

Если чтение не удалось, добавление заблокировано, а на экране есть «Повторить».
При ошибке записи событие остаётся в памяти, сообщение позволяет повторить сохранение.

## Запуск

Из папки `l4_calendar`:

```powershell
flutter pub get
flutter run -d chrome --web-port 8754 --web-hostname 127.0.0.1
```

Или запуск web-сервера с постоянным портом:

```powershell
flutter run -d web-server --web-port 8754 --web-hostname 127.0.0.1
```

Затем открыть http://127.0.0.1:8754. На Android можно запустить `flutter run`, выбрав подключённое устройство.
После добавления пакета нужен полный перезапуск Flutter, одного hot reload недостаточно.
Перед запуском освободи порт, остановив предыдущий запуск приложения.

## Использование

1. Выбрать число в календаре.
2. Нажать `+`, заполнить название, дату `ДД.ММ.ГГГГ` и начало `ЧЧ:ММ`.
3. При необходимости указать окончание и выбрать цвет.
4. Нажать «Сохранить».
5. Для редактирования нажать на событие или выбрать действие в меню `⋮`.
6. Для удаления выбрать «Удалить» в этом меню.

## Структура

| Файл в `lib/` | Назначение |
| --- | --- |
| `main.dart` | Запуск приложения и общая тема |
| `calendar_dates.dart` | Число дней, сравнение дат, разбор и оформление даты и времени |
| `time_input_formatter.dart` | Автоматическое двоеточие при вводе времени |
| `event_colors.dart` | Названия и значения цветов событий |
| `models/calendar_event.dart` | Данные одного события |
| `repositories/event_repository.dart` | Список событий и операции с ним |
| `pages/calendar_screen.dart` | Ручная сетка календаря, выбранная дата и список событий |
| `pages/event_form_page.dart` | Создание и редактирование события с проверками |

Архитектура: `CalendarScreen → CalendarState → EventRepository`.
Подробные объяснения и вопросы для защиты: [LAB4_DEFENSE_GUIDE.md](LAB4_DEFENSE_GUIDE.md).
